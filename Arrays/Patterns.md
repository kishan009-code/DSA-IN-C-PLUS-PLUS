# Array Patterns

## 1. Hashing
**Use when:** Fast lookup, counting, or checking existence is needed.

**Common Data Structures:**
- `unordered_map`
- `unordered_set`

**Common Operations:**
- Store element
- Check if element exists
- Count frequency

**Examples:**
- Two Sum
- Contains Duplicate
- Group Anagrams
- Longest Consecutive Sequence
- Top K Frequent Elements
- Subarray Sum Equals K
